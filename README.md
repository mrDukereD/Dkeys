# DKeys

Крошечная portable-замена WireKeys для Windows: мультибуфер обмена, хоткеи, исправление раскладки, экранные утилиты. Живёт в трее.
Чистый WinAPI на C++ без CRT, одна exe (~170 КБ), настройки в `DKeys.ini`.

**Скачать готовый exe (версия 1.1):** [Releases](https://github.com/mrDukereD/Dkeys/releases/latest)

## Возможности

- **Буферы:** 9 дополнительных буферов: по 10 текстовых записей и по 10 картинок (NumPad): `Ctrl+Num1..9` — скопировать выделенное в буфер (основной буфер Windows не затрагивается; если скопирована картинка или она лежит в буфере Windows — сохраняется PNG, миниатюры 10 в ряд внизу меню, вставка — клик по миниатюре или `Ctrl+цифра`, `0` — десятая; файлы `memory\N_I.png`), `Win+Num1..9` — меню буфера, цифра `1..9`/`0` или Enter — вставить. Меню: `Del` удалить, `F2` править, `Ins` новая запись, `Ctrl+↑/↓` переставить, `←/→` другой буфер, `Tab` — история / запуск / скрипты. Буферы хранятся по файлу в `memory\`.
- **Раскладка:** `Ctrl+`` — исправить RU↔EN (последний набранный текст или выделенное); повторное нажатие возвращает обратно. Работает в Notepad++ и VS Code.
- **Запуск:** хоткеи `run` / `admin`, меню быстрого запуска (`Win+``, секция `[Launcher]`, строка `Название=[Win+C]команда` задаёт ещё и глобальный хоткей, и папка `runs\`: любые файлы — exe, lnk, bat, ps1, pdf, jpg — открываются стандартной программой), переход между вкладками стрелками ←/→, в начале списков — программы из хоткеев ini (`run`/`admin`; `py`, `run python|powershell` — во вкладке «Скрипты») с подписью хоткея справа, `Shift+Enter` — показать файл в проводнике, секция `[Scripts]` (`Win+W=скрипт @ папка`, `Название=[Win+T]скрипт`, `Название=скрипт`; путь без каталога — из `scripts\`), вкладка «Скрипты» (`Win+P`): `*.py`, `*.bat` и `*.ps1` (через PowerShell) из папки `scripts`, имя — первая строка-комментарий, `T` — `tmp.py`, цифры — остальные, окно консоли не закрывается. `pyrun` — выделенное как Python. `topmost`, `totray`.
- **Рисовалка на экране** (`Win+S`): перо, маркер, стрелки, текст, номера, размытие, затемнение, лупа, подсветка курсора; поверх стоп-кадра или живого экрана; Ctrl+мышь — двигать, менять размер и поворачивать готовые фигуры; результат в буфер или PNG.
- **Пипетка** (`Win+Shift+C`): цвет пикселя `#RRGGBB` в буфер, лупа 4x.
- **Запись экрана** (`Win+Shift+R`): H.264 mp4 в папку «Видео», кнопка-кружок скрыта из кадра, звук с микрофона, пауза, выбор монитора или области, панель задач не снимается. Оверлей ввода (клавиши и мышь, пресеты формата [input-overlay](https://github.com/univrsal/input-overlay) из папки `overlays\`) — на видео и/или отдельным файлом на зелёном фоне; в полях пароля клавиши не показываются.
- **Веб-камера** (`Win+K`), **секундомер и таймер**.
- **Дублирование звука** (меню значка): то, что играет на выбранном источнике (или устройстве по умолчанию), воспроизводится ещё и на втором устройстве вывода.
- **Регистратор камеры:** кадр раз в N секунд в `Папка\Камера\год\месяц\день`, свои настройки у каждой камеры, лимит размера папки, красная точка на значке; работает и при закрытом окне камеры. Пропуск тёмных кадров, запись только при движении, дата и время на кадре, контроль свободного места, расписание по часам.
- **Стабильная громкость** (`Win+A` вкл/выкл, `Win+Shift+A` окно): громкость системы сама снижается, когда пик звука выше порога (выстрелы, крики), и плавно возвращается; порог задаётся ползунком на фоне текущего уровня.

Все настройки — в `DKeys.ini` (создаётся при первом запуске, описание у каждой секции), часть — в меню значка в трее.

## Сборка

Нужен MSVC (Visual Studio Build Tools):

```
build.cmd        :: obj\DKeys.exe, затем копия в D:\Progs\DKeys (переменная DEST), аргумент run — запустить
build_dbg.cmd    :: obj\DKeysDbg.exe, лог в %TEMP%\dkeys.log
```

Рядом с exe создаются `DKeys.ini`, `langs\`, `memory\`, `scripts\`, `runs\`, `overlays\` (пресеты кладутся вручную).

Чтобы видеть клавиши в окнах, запущенных от администратора (например, Total Commander), DKeys тоже должен работать от администратора (пункт в меню трея).
