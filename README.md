# DKeys

Крошечная portable-замена WireKeys: мультибуфер обмена и настраиваемые хоткеи в трее.
Чистый WinAPI на C++ без CRT, одна exe (~60 КБ), настройки в `DKeys.ini`.

## Возможности

- 9 дополнительных буферов по 10 записей (только NumPad): `Ctrl+Num1..9` — скопировать выделенное в буфер (основной буфер Windows не затрагивается), `Win+Num1..9` — меню буфера, цифра `1..9`/`0` или Enter — вставить.
- Меню буфера: `Del` удалить, `F2` править, `Ins` новая запись, `Ctrl+↑/↓` переставить, `←/→` другой буфер, `Ctrl+цифра` скопировать запись в другой буфер, `Tab` история/запуск.
- `Ctrl+`` — исправить раскладку RU↔EN (последний набранный текст или выделенное); повторное нажатие возвращает обратно. Работает в Notepad++ и VS Code (замена целой строки).
- Хоткеи на запуск программ, `admin` (от администратора), `py`-макросы и `pyrun` (выделенное как Python), `topmost`, `totray`, меню быстрого запуска `Win+``.
- Буферы хранятся по файлу на буфер в `memory\` и переживают перезагрузку.

Подробности и список действий — в комментариях `DKeys.ini` (создаётся при первом запуске).

## Сборка

Нужен MSVC (Visual Studio Build Tools):

```
build.cmd        :: dist\DKeys.exe
build_dbg.cmd    :: obj\DKeysDbg.exe, лог в %TEMP%\dkeys.log
```

Рядом с exe создаются `DKeys.ini`, `memory\` и `py\`.

Чтобы видеть клавиши в окнах, запущенных от администратора (например, Total Commander), DKeys тоже должен работать от администратора (пункт в меню трея).
